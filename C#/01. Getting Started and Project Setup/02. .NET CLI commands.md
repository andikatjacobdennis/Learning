# .NET CLI Commands

## What is .NET CLI?

The **.NET Command Line Interface (CLI)** is a cross-platform tool used to create, build, run, test, publish, and manage .NET applications from the terminal. The same commands work across **Windows**, **Linux**, and **macOS**.

---

## Check .NET Version

```bash
dotnet --version
```

List all installed SDKs:

```bash
dotnet --list-sdks
```

---

## Create a Solution

```bash
dotnet new sln -n MySolution
```

---

## Create a Project

Console Application

```bash
dotnet new console -n MyApp
```

Class Library

```bash
dotnet new classlib -n MyLibrary
```

Web API

```bash
dotnet new webapi -n MyApi
```

MVC Application

```bash
dotnet new mvc -n MyMvcApp
```

---

## Add Project to Solution

```bash
dotnet sln add MyApp/MyApp.csproj
```

---

## Restore Packages

```bash
dotnet restore
```

---

## Build Project

```bash
dotnet build
```

---

## Run Project

```bash
dotnet run
```

---

## Clean Build Files

```bash
dotnet clean
```

---

## Add NuGet Package

```bash
dotnet add package Serilog
```

---

## Remove NuGet Package

```bash
dotnet remove package Serilog
```

---

## List Installed Packages

```bash
dotnet list package
```

---

## Run Unit Tests

```bash
dotnet test
```

---

## Publish Application

```bash
dotnet publish -c Release
```

---

## Create a New Solution Structure

```bash
dotnet new sln -n Demo

dotnet new webapi -n Demo.Api

dotnet new classlib -n Demo.Core

dotnet sln add Demo.Api/Demo.Api.csproj

dotnet sln add Demo.Core/Demo.Core.csproj
```

---

## Useful Commands

| Command                 | Description             |
| ----------------------- | ----------------------- |
| `dotnet new`            | Create a new project    |
| `dotnet restore`        | Restore NuGet packages  |
| `dotnet build`          | Build the project       |
| `dotnet run`            | Run the application     |
| `dotnet clean`          | Remove build outputs    |
| `dotnet test`           | Run unit tests          |
| `dotnet publish`        | Publish the application |
| `dotnet add package`    | Install a NuGet package |
| `dotnet remove package` | Remove a NuGet package  |
| `dotnet list package`   | List installed packages |

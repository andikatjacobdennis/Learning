In C#, `appsettings.json` is commonly used to store application configuration (connection strings, API keys, feature flags, custom settings, etc.). The way you read it depends on the application type (.NET Core / .NET 5+ / .NET 6+).

## 1. Create `appsettings.json`

Example:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=myServer;Database=myDb;Trusted_Connection=True;"
  },
  "AppSettings": {
    "ApplicationName": "MyApp",
    "MaxRetryCount": 3
  }
}
```

Make sure it is copied to the output directory:

**Visual Studio → appsettings.json → Properties → Copy to Output Directory → Copy if newer**

---

## 2. Install configuration packages (if needed)

For a console application:

```bash
dotnet add package Microsoft.Extensions.Configuration
dotnet add package Microsoft.Extensions.Configuration.Json
```

---

## 3. Read configuration manually

Example for a console app:

```csharp
using Microsoft.Extensions.Configuration;

var configuration = new ConfigurationBuilder()
    .AddJsonFile("appsettings.json", optional: false, reloadOnChange: true)
    .Build();

string connectionString = configuration.GetConnectionString("DefaultConnection");

string appName = configuration["AppSettings:ApplicationName"];

int retryCount = configuration.GetValue<int>("AppSettings:MaxRetryCount");

Console.WriteLine(connectionString);
Console.WriteLine(appName);
Console.WriteLine(retryCount);
```

---

## 4. Using Dependency Injection (`IConfiguration`)

In .NET 6+ applications, configuration is already registered.

Example:

```csharp
public class MyService
{
    private readonly IConfiguration _configuration;

    public MyService(IConfiguration configuration)
    {
        _configuration = configuration;
    }

    public void PrintSettings()
    {
        var name = _configuration["AppSettings:ApplicationName"];

        Console.WriteLine(name);
    }
}
```

---

## 5. Strongly typed configuration (recommended)

Create a class:

```csharp
public class AppSettings
{
    public string ApplicationName { get; set; }
    public int MaxRetryCount { get; set; }
}
```

Register it:

```csharp
builder.Services.Configure<AppSettings>(
    builder.Configuration.GetSection("AppSettings"));
```

Use it:

```csharp
using Microsoft.Extensions.Options;

public class MyService
{
    private readonly AppSettings _settings;

    public MyService(IOptions<AppSettings> options)
    {
        _settings = options.Value;
    }

    public void Print()
    {
        Console.WriteLine(_settings.ApplicationName);
        Console.WriteLine(_settings.MaxRetryCount);
    }
}
```

---

## 6. ASP.NET Core example (`Program.cs`)

```csharp
var builder = WebApplication.CreateBuilder(args);

var connectionString =
    builder.Configuration.GetConnectionString("DefaultConnection");

Console.WriteLine(connectionString);

var app = builder.Build();

app.Run();
```

## Access patterns summary

| Configuration     | Code                           |
| ----------------- | ------------------------------ |
| Simple value      | `configuration["Key"]`         |
| Nested value      | `configuration["Section:Key"]` |
| Integer/boolean   | `GetValue<int>("Key")`         |
| Connection string | `GetConnectionString("Name")`  |
| Typed settings    | `IOptions<T>`                  |

For modern .NET applications, **strongly typed configuration with `IOptions<T>` is usually the preferred approach** because it provides better maintainability and compile-time structure.

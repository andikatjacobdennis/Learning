# Top-level Statements (C# 9+)

Top-level statements allow writing C# code without explicitly creating a `Program` class and `Main()` method.

## Traditional Style

```csharp
using System;

namespace MyApp;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello World");
    }
}
```

## Top-level Statement Style

```csharp
Console.WriteLine("Hello World");
```

The compiler automatically creates:

```csharp
class Program
{
    static void Main(string[] args)
    {
    }
}
```

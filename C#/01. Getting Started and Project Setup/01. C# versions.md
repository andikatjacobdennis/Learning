# C# Versions

## What are different C# Version?

| Version | .NET               | Key Features                                                              |
| ------- | ------------------ | ------------------------------------------------------------------------- |
| C# 1.0  | .NET Framework 1.0 | Classes, Objects, Interfaces                                              |
| C# 2.0  | .NET Framework 2.0 | Generics, Nullable Types                                                  |
| C# 3.0  | .NET Framework 3.5 | LINQ, Lambda Expressions, Extension Methods                               |
| C# 4.0  | .NET Framework 4.0 | `dynamic`, Named & Optional Parameters                                    |
| C# 5.0  | .NET Framework 4.5 | `async` / `await`                                                         |
| C# 6.0  | .NET Framework 4.6 | String Interpolation, `nameof`                                            |
| C# 7.x  | .NET Core          | Tuples, Pattern Matching, Local Functions                                 |
| C# 8.0  | .NET Core 3.0      | Nullable Reference Types, Ranges, Indices                                 |
| C# 9.0  | .NET 5             | Records, Top-level Statements                                             |
| C# 10   | .NET 6 (LTS)       | Global Usings, File-scoped Namespaces                                     |
| C# 11   | .NET 7             | Required Members, Raw String Literals                                     |
| C# 12   | .NET 8 (LTS)       | Primary Constructors, Collection Expressions                              |
| C# 13   | .NET 9             | `params` Collections, Improved Lock Support                               |
| C# 14   | .NET 10 (LTS)      | `field` keyword, Implicit Span Conversions, Null-conditional Assignments  |

## Set C# Version

```xml
<PropertyGroup>
    <LangVersion>14.0</LangVersion>
</PropertyGroup>
```

Or use:

```xml
<LangVersion>latest</LangVersion>
```

## Recommendation

* **New Projects:** C# 14
* **Production (LTS):** C# 14 with .NET 10 LTS

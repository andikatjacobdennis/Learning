# Global Using Directives (C# 10+)

Global using directives allow namespaces to be imported once and used across all `.cs` files in a project.

## Without Global Using

Every file needs:

```csharp
using System;
using System.Collections.Generic;
using System.Linq;

namespace MyApp;

class Service
{
    public void Run()
    {
        Console.WriteLine("Hello");
    }
}
```

---

## With Global Using

Create a file:

```
GlobalUsings.cs
```

Add:

```csharp
global using System;
global using System.Collections.Generic;
global using System.Linq;
```

Now any `.cs` file can use these namespaces:

```csharp
namespace MyApp;

class Service
{
    public void Run()
    {
        Console.WriteLine("Hello");
    }
}
```

---

## Global Using with Project File

Enable automatic global usings:

```xml
<PropertyGroup>
    <ImplicitUsings>enable</ImplicitUsings>
</PropertyGroup>
```

The compiler generates common global usings automatically.

Example:

```csharp
global using System;
global using System.Collections.Generic;
global using System.IO;
global using System.Linq;
global using System.Net.Http;
global using System.Threading;
global using System.Threading.Tasks;
```

---

## Global Static Using

Import static members:

```csharp
global using static System.Math;
```

Usage:

```csharp
var result = Sqrt(25);
```

---

## Global Using Alias

Create an alias:

```csharp
global using Json = System.Text.Json.JsonSerializer;
```

Usage:

```csharp
var json = Json.Serialize(data);
```

---

## Disable Implicit Usings

In `.csproj`:

```xml
<PropertyGroup>
    <ImplicitUsings>disable</ImplicitUsings>
</PropertyGroup>
```

---

## Rules

* `global using` must appear before normal code.
* Can be placed in any `.cs` file.
* Cannot duplicate normal `using` directives.
* Applies to the entire project.

---

## Common Practice

```
MyApp
│
├── Program.cs
├── GlobalUsings.cs
└── Services/
    └── UserService.cs
```

`GlobalUsings.cs`

```csharp
global using Microsoft.Extensions.Logging;
global using Microsoft.Extensions.DependencyInjection;
global using System.Text.Json;
```

## Benefits

* Reduces repeated `using` statements.
* Cleaner source files.
* Common in modern .NET projects.

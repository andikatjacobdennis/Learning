### Command-line arguments in C# (practical)

Command-line arguments are values passed to a C# program when starting it from a terminal.

### 1. Read arguments using `args`

```csharp
class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine(args[0]);
    }
}
```

Run:

```bash
MyApp.exe John
```

Output:

```bash
John
```

---

## 2. Using `System.CommandLine` NuGet package

Install:

```bash
dotnet add package System.CommandLine
```

Now instead of:

```csharp
if (args[0] == "--name")
{
    // manually handle value
}
```

### Example: Named arguments with `System.CommandLine`

```csharp
using System.CommandLine;

var nameOption = new Option<string>(
    "--name",
    "The user's name");

var ageOption = new Option<int>(
    "--age",
    "The user's age");

var rootCommand = new RootCommand("Sample application");

rootCommand.AddOption(nameOption);
rootCommand.AddOption(ageOption);

rootCommand.SetHandler((name, age) =>
{
    Console.WriteLine($"Name: {name}");
    Console.WriteLine($"Age: {age}");
},
nameOption,
ageOption);

return await rootCommand.InvokeAsync(args);
```

Run:

```bash
MyApp.exe --name John --age 25
```

Output:

```bash
Name: John
Age: 25
```

---

## Why use `System.CommandLine`?

### 1. Automatic help generation

With manual parsing, you have to write help messages yourself.

With `System.CommandLine`:

```bash
MyApp.exe --help
```

Automatically gives:

```bash
Description:
  Sample application

Options:
  --name <name>     The user's name
  --age <age>       The user's age
  --help            Show help
```

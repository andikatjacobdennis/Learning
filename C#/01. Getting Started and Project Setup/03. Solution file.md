# `.slnx` Solution File (.NET 10)

* Root element is `<Solution>`.
* You can group projects into folders by wrapping the <Project> elements inside a <Folder> element.
* Each project is added using `<Project>`.
* `Path` is relative to the solution file.
* `.slnx` only references projects; it doesn't store source code.

## Basic Structure

```xml
<Solution>
  <Folder Name="/src/">
    <Project Path="src/MyApp.Api/MyApp.Api.csproj" />
    <Project Path="src/MyApp.Application/MyApp.Application.csproj" />
    <Project Path="src/MyApp.Domain/MyApp.Domain.csproj" />
    <Project Path="src/MyApp.Infrastructure/MyApp.Infrastructure.csproj" />
  </Folder>

  <Folder Name="/tests/">
    <Project Path="tests/MyApp.Tests/MyApp.Tests.csproj" />
  </Folder>
  
  <Folder Name="/Solution Items/">
    <File Path="README.md" />
    <File Path=".github/workflows/build.yml" />
  </Folder>
</Solution>
```

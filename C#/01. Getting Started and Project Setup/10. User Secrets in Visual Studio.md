# 1. Enable User Secrets in Visual Studio

### Option A: From Solution Explorer

1. Open your project in **Visual Studio**.
2. In **Solution Explorer**, right-click your project.
3. Select:

```
Manage User Secrets
```

Visual Studio will create a `secrets.json` file and add a `UserSecretsId` to your `.csproj`.

Your `.csproj` will contain something like:

```xml
<PropertyGroup>
  <UserSecretsId>your-project-guid</UserSecretsId>
</PropertyGroup>
```

---

## 2. Add secrets

Visual Studio opens a `secrets.json` file.

Example:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=localhost;Database=MyDb;User Id=sa;Password=myPassword;"
  },
  "ApiKeys": {
    "GoogleMaps": "abc123xyz"
  }
}
```

This file is stored outside your project folder, usually under your user profile:

```
%APPDATA%\Microsoft\UserSecrets\<UserSecretsId>\secrets.json
```

It is **not added to Git**.

---

## 3. Read secrets in your application

### Using `IConfiguration`

In `Program.cs`:

```csharp
var builder = WebApplication.CreateBuilder(args);

var apiKey = builder.Configuration["ApiKeys:GoogleMaps"];

Console.WriteLine(apiKey);

var app = builder.Build();

app.Run();
```

ASP.NET Core automatically loads User Secrets when running in the **Development** environment.

## 4. Using dependency injection

Example:

`appsettings.json`

```json
{
  "ApiSettings": {
    "Url": ""
  }
}
```

`secrets.json`

```json
{
  "ApiSettings": {
    "ApiKey": "secret-key"
  }
}
```

Create a class:

```csharp
public class ApiSettings
{
    public string ApiKey { get; set; }
}
```

Register it:

```csharp
builder.Services.Configure<ApiSettings>(
    builder.Configuration.GetSection("ApiSettings"));
```

Use it:

```csharp
public class MyService
{
    private readonly ApiSettings _settings;

    public MyService(IOptions<ApiSettings> options)
    {
        _settings = options.Value;
    }
}
```

## 5. Using the .NET CLI

You can also manage secrets from the terminal.

### Initialize secrets:

```bash
dotnet user-secrets init
```

### Add a secret:

```bash
dotnet user-secrets set "ApiKeys:GoogleMaps" "abc123xyz"
```

### List secrets:

```bash
dotnet user-secrets list
```

### Remove a secret:

```bash
dotnet user-secrets remove "ApiKeys:GoogleMaps"
```

## 6. Connection string example

Add:

```bash
dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=myserver;Database=mydb;User Id=user;Password=password"
```

Read:

```csharp
var connectionString =
    builder.Configuration.GetConnectionString("DefaultConnection");
```

---

## 7. Important notes

✅ Good for:

* API keys
* Local database passwords
* Development tokens
* Third-party service credentials

❌ Not for:

* Production secrets
* Shared team credentials
* Deployment environments

For production, use tools like:

* Azure Key Vault
* AWS Secrets Manager
* Environment variables
* HashiCorp Vault

A common workflow is:

```
appsettings.json
        +
appsettings.Development.json
        +
User Secrets (local)
        +
Environment Variables (production)
        ↓
 IConfiguration
```

ASP.NET Core combines these sources automatically, with later sources overriding earlier ones.

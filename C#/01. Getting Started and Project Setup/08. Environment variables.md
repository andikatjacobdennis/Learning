# Environment Variables

## 1. What are environment variables?

An environment variable is a **key-value pair stored by the operating system**.

Example:

```bash
DATABASE_CONNECTION=Server=myserver;Database=mydb;
API_KEY=abc123xyz
APP_MODE=Production
```

Your C# application reads these values at runtime.

### Why use them?

Instead of writing:

```csharp
string apiKey = "abc123xyz";
```

you store:

```bash
API_KEY=abc123xyz
```

and read it:

```csharp
string? apiKey = Environment.GetEnvironmentVariable("API_KEY");
```

Benefits:

* Secrets are not committed to Git
* Different settings for Development/Test/Production
* Easier cloud deployment
* Cleaner configuration management

# Step 1: Create an environment variable

## Windows

Open Command Prompt:

```cmd
setx API_KEY "my-secret-key"
```

Close and reopen the terminal.

Check:

```cmd
echo %API_KEY%
```

Output:

```bash
my-secret-key
```

Open:

```bash
Program.cs
```

```csharp

```

Run:

```bash
dotnet run
```

Output:

```bash
my-secret-key
```

# Step 4: Handle missing variables safely

Never assume the variable exists.

Bad:

```csharp
string key = Environment.GetEnvironmentVariable("API_KEY");
```

This can cause problems because the result can be null.

Better:

```csharp
string? key = Environment.GetEnvironmentVariable("API_KEY");

if (string.IsNullOrEmpty(key))
{
    Console.WriteLine("API_KEY is missing");
    return;
}

Console.WriteLine(key);
```

# Step 5: Create environment variables from C#

You can also create them programmatically.

```csharp
Environment.SetEnvironmentVariable(
    "APP_MODE",
    "Development"
);
```

Read it:

```csharp
var mode = Environment.GetEnvironmentVariable("APP_MODE");

Console.WriteLine(mode);
```

Output:

```
Development
```

# Step 6: Understand variable scope

Environment variables have scopes.

## Process scope

Only current application:

```csharp
Environment.SetEnvironmentVariable(
    "TEST_VALUE",
    "123",
    EnvironmentVariableTarget.Process
);
```

When your app closes, it disappears.

---

## User scope

Available to your user account:

```csharp
Environment.SetEnvironmentVariable(
    "TEST_VALUE",
    "123",
    EnvironmentVariableTarget.User
);
```

---

## Machine scope

Available to all users:

```csharp
Environment.SetEnvironmentVariable(
    "TEST_VALUE",
    "123",
    EnvironmentVariableTarget.Machine
);
```

Requires administrator permission.

# Step 7: Real-world example - Database connection

Instead of:

```csharp
var connectionString =
    "Server=localhost;Database=Shop;User=admin;Password=1234";
```

Use:

Environment variable:

```bash
DB_CONNECTION=
Server=localhost;Database=Shop;User=admin;Password=1234
```

C#:

```csharp
string? connectionString =
    Environment.GetEnvironmentVariable("DB_CONNECTION");


if(connectionString == null)
{
    throw new Exception(
        "Database connection missing"
    );
}

Console.WriteLine(connectionString);
```
